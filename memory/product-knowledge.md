# Product knowledge — outcomes, briefs and marks

- **Foundations before autonomy**: do not push for more autonomy while the operator context file, per-episode `requests.log` telemetry or the guarded verification environment is missing, because agents that cannot prove their own work only move faster in some direction. source: `s03e01/LESSON-NOTES.md` · how: read
- **Ask the owner, never outrank them**: an unresolved conflict goes to the person who owns it as one question and the build waits, because a builder who picks a side turns a disagreement into rework nobody can trace to a choice. source: operator correction after the S03E01 debrief · how: told
- **A symptom is not a brief**: a request that opens with "it fails" or a bare command gets one line written back before diagnosis — what the human can do once it is fixed, and the command, log line or file that proves it — because a fix judged after the fact costs a follow-up turn per attempt; `node tools/brief.mjs --job <id>` writes it and refuses an incomplete one. source: `s03e02/LESSON-NOTES.md` · how: read
- **A brief says what it must not do**: name the boundaries and negative examples beside the target — the file it must not touch, the output it must not produce — because an agent told only the destination reaches it through whatever it can; `tools/brief.mjs` refuses a brief without `boundaries`. source: `s03e02/LESSON-NOTES.md` · how: read
- **One decision, one issue**: two requests that pull against each other, or a request and its withdrawal, become one issue whose `sources` name both, because closing one half leaves the other looking like work nobody owns. source: `triage` skill · how: ran
- **Poll a request stream to its last page**: poll until a channel returns nothing before triaging, because the S03E02 collectors gave 9 of 21 requests on the first pass and the claim was refused until all 21 were in. source: `s03e02/triage.mjs` · how: ran
- **A mark quotes a rule**: every open issue is `agent-ready` or `needs-human` and cites the line it rests on, read from the spec by the check rather than from memory, because a mark without a citation is an opinion. source: `s03e02/triage.mjs` · how: ran
- **Build a few pieces well rather than all at once**: accept part of a process and let the gate show whether it earns its place, because adopting every mechanism at once hides which one is doing the work. source: `s03e04/LESSON-NOTES.md` · how: read
