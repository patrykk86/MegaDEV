# Architecture knowledge — how the primitives fit

The layers in order: guard → loop → journal → sanitize → approvals → recall → memory budget → scheduler
and gateway → ambient listener. Each module carries a docblock, most carry a `.tool.json`.

- **Every autonomous loop runs through `tools/agent-loop.mjs` under `tools/agent-guard.mjs`**: empirical limits from `tools/model-limits.json` (mean × 1.5), sandboxed paths, shell allowlisting, fail-closed policy, own-property dispatch, and no chaining, subshells or redirects; a call rewritten by a `beforeTool` hook is re-checked before it runs, so the guard is the contract. source: `AGENTS.md` §7 · how: read
- **Routing never downgrades security**: `routeModel` matches `SECURITY_SENSITIVE_PATTERN` (security, vulnerab, exploit, secret, credential, encrypt, auth, compliance, gdpr, phi, pii) and sends it to the reasoning tier, never the lightweight one; reviewer dispatches use the security tier in `.agents/model-routing.json`, and both stay in parity with that file. source: `AGENTS.md` §9, `.clinerules` §3 · how: read
- **Guarded calls land in `.runs/journal.jsonl`** with SHA-256 hash chaining and outbound redaction; `tools/journal.mjs` is the read side, so the trail proves to a machine what ran. source: `AGENTS.md` §9 · how: read
- **Memory is a tree**: [MEMORY.md](MEMORY.md) is the index and loads as a hard rule; each subject it links loads as its own soft rule in link order; `tools/memory/rule-budget.mjs` demotes the tail once `AGENTS.md` plus memory passes 24,000 tokens or 36,864 bytes, and the advisory manifest names the demoted file to read on demand. Caps: index 3,072 B, subject 4,096 B; `node tools/check.mjs` fails a dangling link, an unlinked file or an oversized subject. source: `tools/memory/rule-budget.mjs` · how: ran
- **Over budget is measured, not guessed**: `enforceRuleBudget` over `AGENTS.md` plus one memory file reported `demoted 1, manifest true` at 25,487 B — the whole block reduced to one advisory line — which is why the tree exists and why prose is tightened before bytes are added. source: `s03e04/LESSON-NOTES.md` · how: ran
- **Background work never blocks the coordinator**: delegate through the `crew` skill, `tools/scheduler/runner.mjs` or `tools/gateway/task-bridge.mjs`; a detached job reports PID, log path and result path in the turn that starts it, results land in `.runs/<job>/result.json` scrubbed of tokens and PHI/PII, and work that stays open waits behind a standing watcher rather than a held shell. source: `AGENTS.md` §4 · how: read
- **Past notes arrive through `tools/memory/contextual-recall.mjs`**, bounded by the same budget, never by pasting whole transcripts. source: `AGENTS.md` §8 · how: read
- **Ambient listeners stay inside the workspace root**, coalesce events, deduplicate task ids and contain their own errors (`tools/ambient-listener.mjs`). source: `AGENTS.md` §9 · how: read
- **A view a person can read exists**: `node tools/product-view.mjs` renders the flows, the paths they leave and the gates that prove them, and `--out` writes it under `.runs/<job>/`. source: `s03e03/LESSON-NOTES.md` · how: ran
- **`.gemini/` and `.copilot/` are copied Antigravity brains**: read-only knowledge and out of the scanner, consulted only when a gap needs them, through `s03e01/digest-brain.mjs` rather than a grep over 32 MB of JSONL, and never committed. source: operator instruction, 2026-11-12 · how: told
