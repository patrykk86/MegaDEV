# API knowledge — reaching the outside world

- **Course traffic goes through `tools/hub-client.mjs`**: the single client, which masks secrets in logs; every script that calls the Challenge Hub over HTTP uses it, a second client is a defect the gate reports, and its contract is `tools/hub-client.tool.json`. source: `AGENTS.md` §3, `.clinerules` §2 · how: read
- **`mega-challenge` is the one documented exception**: an operator-controlled `npx`/`mcp-remote` transport, declared in `.agents/mcp_config.json` and enabled per task in `.cline/mcp.json`, that authenticates through the MCP auth flow. Code never adds a second credentialed path and never shells out to the same endpoint with inline credentials; pin the package version before unattended automation. source: `.clinerules` §4 · how: read
- **Each enabled MCP server injects every one of its tool schemas into every request**, so the default is an empty `mcpServers` map and `cloudflare` stays declared-not-loaded until a task needs it, then is removed in the same session. source: `.clinerules` §4 · how: read
- **Contract first**: discover the shape (link headers, `schema.json`, OpenAPI) before sending a payload, because a guessed endpoint shape fails after the work is done. source: `.clinerules` §2 · how: read
- **A whole-codebase Firebase functions deploy is blocked by a stale function**: deploy as `--only functions:default:status`, because `--only functions` aborts on a `pulse` function absent from local source and `functions:status` matches nothing without the codebase prefix; never add `--force`, which deletes the operator's function. source: `s02e03/firebase` deploy, 2026-11-10 · how: ran
- **Deliver with the challenge identity**: course deliverables go out under that identity — never the operator's personal account and never `github-mcp-server` — because the account a commit carries is not a detail to switch later. source: `AGENTS.md` §1 · how: read
- **A run that costs money waits for a yes**: `mega-examples` model runs are paid, so they happen only when the operator asks. source: `AGENTS.md` §2 · how: read
